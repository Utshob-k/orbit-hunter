The atlas list of 415 entries used in the comparison is a local copy and is not in this repository. The text is the rules file of the run, with the local file and folder names replaced by "the run folder" (a folder outside the repository) and nothing else changed.
Written at machine clock 2026-10-13 09:02:08, before any script of this part was run. Every later change is declared at the end of this file before it was run. Results went to separate files of the run folder; no file name of an earlier run was reused. The results are in results-class-i-13-20.txt.

QUESTION. At the branch points nu_upper = 1/n, n = 13 to 20 (the members of R are linearly stable there; the class C satellite of the same n is already unstable), does the isosceles class still have a satellite family, and how does its end orbit compare with the class C satellite of the same n?

PRE-REGISTERED CRITERION FOR "DIFFERENT" (fixed now; both orbits may be unstable, so stability alone does NOT count). An end orbit (a zero of theta on a curve of the non-repeat root) counts as DIFFERENT from the class C satellite of the same n only if BOTH hold:
 (a) its symmetry class differs, as for n = 5 to 12: the end orbit has an isosceles state (apex body 0, residual below 1e-9 in the scan of iso-end-orbit-check.mjs) and NO collinear perpendicular state (smallest residual above 1e-4), while the class C orbit has a collinear perpendicular state and no isosceles state with any body as apex;
 (b) EITHER (b1) T* or L* of the two orbits differ by more than 100 times the larger of the two 30 digit closures (class I: closure_full_period of the refined file; class C: the closure of its 30 digit orbit in data/satellite-candidates.json, 4e-25 to 2e-24; so about 2e-22 relative or smaller), OR (b2) the moduli of the largest multipliers (the largest modulus of the four nontrivial multipliers, tier A) differ by more than 1e-6 relative.
 STATED IN ADVANCE: (b) is easy to meet (the two orbits of n = 5 to 12 differ in T* by 2e-8 to 4e-7 relative, in L* by 2e-5 to 7e-4, far above 1e-22); so (a) carries the weight, and what the criterion shows is that the end orbit is an orbit with another symmetry class and other values, nothing about how the two families are related.
 An end orbit that has BOTH symmetric states is reported as "both classes: the class C orbit seen from the isosceles side", not as a second family.
 "ESTABLISHED" only if its 30 digit closure (closure_full_period) is below 1e-20 AND the REBOUND distance to the start state after ONE period is below 1e-9. (Declared now, because the period count was left open: the 2, 5, 10 and 20 period distances are reported but are not part of the threshold; for an unstable orbit the distance grows like mu^k, so the 20 period value is expected to be larger and is read against the multiplier.) Otherwise "not established", and then nothing is claimed.
 A curve that stops without a zero is reported as such (the reason of the tool: collapse of the step, closest approach, step limit), and nothing is claimed beyond it. If no sense reaches a zero for an n, that n has no end orbit and no comparison.

CLASS C MULTIPLIERS (item 4). Tier A files of class C for n = 13 to 20 did not exist: data/stability-mp/class-c/ of the tag has the cases 5 to 12 only, and the earlier run of those cases has 5 to 12 only; for n = 13 to 20 the stored values are the double precision largest multipliers of data/satellite-candidates.json (1.712, 2.609, 3.426, 4.235, 5.054, 5.890, 6.745, 7.621). So all eight are computed here with the released monodromy-mp.py, tier A (the stored 30 digit orbit, 50 digits, tolerance 1e-36, h = 1e-10), with the output in the run folder (class-c-<n>-A.json) and one log per n. They need nothing from the class I search, and they are started at the same time as the class I searches (16 processes on 12 logical processors, so every time is for a loaded machine); the comparison is made only when both are finished.

ATLAS AND CPC (S4), for every end orbit found before any claim: the method of tools/compare-atlas-all.py as implemented in iso-end-orbit-check.mjs on the local list of the 415 equal-mass L != 0 entries (the 14 bhhsat entries included): MATCH = L* within 1e-5 relative, T* within 1e-5 relative where one of the two is k times the other (k = 1 to 12), and the number of syzygies agrees; NEAR = the same with 5e-3; the nearest entries are printed. The 99 rows of the CPC table (data/cpc-converted.json of the tag): the same T*, L* test without the syzygy count (relatively periodic orbits with theta not 0, so a coincidence in (T*, L*) would not make the orbits the same). WORDING: never "new"; "not found in the sources checked" only after this comparison.

HOW IT IS RUN. The eight class I pipelines (one shell script per n and theta) and the eight class C jobs (one shell script per n) are started as DETACHED processes (PowerShell Start-Process, hidden window), not as children of a launcher; each writes its own log with start and end times of the machine clock. Only the processes of this run are ever stopped, by command line. Nothing is overwritten (the tools refuse to overwrite an --out file; a failed attempt is kept and noted, and a rerun gets other names declared below). TIME LIMIT: 3 hours of wall time from the first start (clock in the clock file of the launch); a job not finished then is stopped and reported.

PREDICTIONS (written before the run; confidence per n in brackets).
 (P1) The member nu = 1/n is found in the isosceles chart, the n fold repeat closes with 8 pieces, the null space is 2 dimensional and the bifurcation equation has two real roots (the repeat and one other) [90 percent each; n = 5 to 12 did, 8 of 8].
 (P2) The non-repeat root reaches a zero of theta in at least one sense [85 percent each]; in both senses: n = 13, 14, 15 [70 percent each], n = 16 to 20 [25 percent each] (the class C curves did so; for n = 16 to 20 one sense stopped by a collapse of the step). A zero in no sense for at least one of the eight n: [30 percent].
 (P3) The end orbit satisfies the criterion DIFFERENT and is established [80 percent each, 85 percent that at least seven of the eight].
 (P4) Stability type of the class I end orbit: unstable with two real pairs (a positive pair near 1.05 and a negative pair, because the elliptic pair of n = 12 had its angle at 0.4506 and the class I angle lies above the class C one, so the collision at -1 is expected to have happened by n = 13) [60 percent each]; unstable with a positive real pair and an elliptic pair as for n <= 12 [25 percent]; stable or another type [15 percent]. Largest multiplier modulus of the class I orbit above that of the class C orbit of the same n [65 percent each]. The class C orbits have, as stored in double precision, a real negative largest multiplier for n = 13 to 16 and the modulus 1.71 to 7.6.
 (P5) The end orbit lies on the same side of the branch point as the class C one (L* of every point of the curve below L* of the member) [90 percent each].
 (P6) No end orbit matches an atlas entry or a CPC row at 1e-5 [90 percent each]; no NEAR (5e-3, same number of syzygies) [85 percent each].
 (P7) Time: each class I pipeline inside 60 minutes [75 percent each]; each class C tier A job inside 60 minutes [80 percent each]; the whole part inside 2 hours [75 percent], inside the limit of 3 hours [90 percent].
NOT DONE: n >= 21, the lower nu, the other apex bodies, orbits without these symmetries, tier B, any change of src/.
