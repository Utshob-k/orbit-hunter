SHORT ANSWER (B1). The retraces equal the stored curves, the reduction is right, and the picture along the curves is this:
1. TRANSVERSE pair. For n = 5 to 12 it is on the unit circle along the whole curve in both classes. For n = 13 to 20 it is on the unit circle for the first 90 to 99 percent of the curve (in L*, counted from the branch point to the end orbit) and becomes real negative once, in every curve (21 curves, both classes, both senses where both reach theta = 0); it reaches -1 between the brackets listed in a file of the run folder, always before the zero: for n = 13 at L* 2.6661 to 2.6702 in class C and 2.6683 to 2.6717 in class I (the zero is at 2.6647 in class C), for n = 20 at L* 2.733 to 2.737 (the zero is at 2.688). The crossing L* rises with n, so for n = 12 it would lie at or after the end of the curve; the only trace of it is that the point just PAST the zero of the class I curve of n = 12, sense -1, is real negative (one point, not counted). This is the answer to "where along each curve the transverse pair reaches -1".
2. RESONANT pair. Its type is NOT the same along the whole curve. For n = 5 it is elliptic (class C) and real positive (class I) from the first point at which it can be classified (s = 0.76 to 0.94, L* 2.5865) to the end. For n = 6 to 20 it is REAL POSITIVE (hyperbolic) in the middle of the class C curve and ELLIPTIC only at the end, and in class I the other way round: ELLIPTIC in the middle and REAL POSITIVE at the end. The change happens at nearly the same L* in the two classes (for n = 12: 2.7030 to 2.7069 in class C, 2.7048 to 2.7083 in class I) and at a fraction of the way from the branch point to the end orbit that grows with n (0.46 at n = 6, 0.84 at n = 12, 0.90 at n = 20: fractions of the L* difference between the branch point and the end orbit, each at one edge of one bracket; with both edges of the brackets of both classes the fraction is 0.42 to 0.48 at n = 6, 0.82 to 0.84 at n = 12 and 0.89 to 0.90 at n = 20, from the L* of the brackets printed by tools/curve-multiplier-types.mjs and the L* of the branch point and of the end orbit). So the end orbits are elliptic (class C) and hyperbolic (class I), as the tier A values say, but a point in the middle of the curve is the reverse. The pilot's observation (an earlier local test: the small pair of class C n = 12 turns real in the middle) is CONFIRMED by the reduction; it was not an artefact of relativeStability.
3. No complex quadruplet occurs on any curve. The tracking by continuity is unambiguous at every step; the only ambiguity is at the very first classified point of the 10 curves with n >= 16 (the other root of y is within 1e-2 of 2 at the branch point there), and it does not matter: at the zero of every one of the 53 curves the tracked resonant pair is the pair nearest +1, with a margin of at least 200 in |y - 2| (smallest: class C n = 6, sense -1). So the identification of the resonant pair as "the pair nearest +1 at the end orbit" equals its identification by continuity from the branch point, for n = 5 to 20, both classes, all senses.

WHAT FAILED OR WAS AMBIGUOUS. (1) P4, P5, P11 as above. (2) The classification of the resonant pair starts only where |y - 2| >= 1e-6; before that point (s up to 0.8 for n = 5, up to 4.9 for n = 13..20 in some curves) the pair is within the noise of the double multiplier +1 and nothing is claimed; so for n = 5 a hyperbolic stretch of the class C curve before s = 0.8 (as n = 6 shows from its first classified point) cannot be excluded or confirmed. (3) The 3-point rule hides a change that is shorter than 3 classified points: one end run is listed, the class I curve of n = 12, sense -1 (the transverse pair of the point past the zero, real negative modulus 1.47). (4) The type changes are given as brackets between two accepted points (typically 0.001 to 0.005 wide in L*); no crossing was refined. (5) The tracking follows y by the smallest change; a crossing of y_R and y_T would show up as an ambiguous step, and none occurred after the first point. (6) The curves are the double precision continuation with the zero at 1e-11 turns or better; the end orbit is the 30 digit orbit, checked in (a) and (b).

WHAT THIS DOES NOT SHOW. It does not show that the transverse pair reaches -1 at a point where a branch or a bifurcation of the curve occurs (nothing special in the curve was looked for), nor why the resonant pair changes type at the L* where it does; it does not say what the curves do beyond their zero (the point past the zero is one point); it does not cover the lower rotation number, the curves that stop by a collapse of the step, n >= 21 (B1 was run for n = 5..20 only), or orbits outside the two symmetry classes; the multipliers are linear and in double precision along the curves (tier A only at the end orbits); the figure shows four orbits, not a trend.
