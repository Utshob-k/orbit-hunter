RESULTS of the search of class I (the isosceles class, apex body 0) at the upper-nu branch points nu = 1/n, n = 13 to 20, and the comparison with the class C satellite of the same n (version 0.2.29). Rules: rules-class-i-13-20.txt (written at machine clock 2026-10-13 09:02:08, before any run; four declarations at its end, each written before the thing it concerns was run or read). The 16 jobs ran from 09:04:51 (the clock file of the fourth launch) to 10:17:22 (the last class I pipeline) on a loaded machine (16 jobs on 12 logical processors). The three failed launches that came before started no computation (see below). The files kept in this repository are listed at the end of this file.

SHORT ANSWER. At every one of the eight branch points the isosceles class still has a satellite family: the member is found, the null space is 2 dimensional, there are two real roots, and the non-repeat root runs to a zero of theta (a periodic orbit) in at least one sense for all eight n (in both senses for n = 13 and 14, in one sense for n = 15 to 20). The end orbit of each is established (30 digit closure 5.7e-25 to 3.6e-24, REBOUND distance to the start after one period 9e-15 to 3e-13), has an isosceles state and no collinear one (the class C orbit the reverse), differs from the class C orbit of the same n in T* by 3.3e-7 to 3.6e-7 and in L* by 7.2e-4 to 1.07e-3 (relative), and so is DIFFERENT by the criterion written before the run, for all eight. Both orbits are unstable here, so the stable-unstable pairing seen for n = 5 to 12 is gone: the class C orbit has a real negative pair (modulus 1.71 at n = 13 to 7.62 at n = 20) and a small elliptic angle (0.0082 to 0.0071 turns); the class I orbit has TWO real pairs, a positive one (1.0531 at n = 13 to 1.0459 at n = 20, the same pair that was 1.0547 at n = 12) and a negative one (2.164 at n = 13 to 8.426 at n = 20), 26 percent above the class C negative modulus at n = 13 and 11 percent at n = 20. No end orbit matches an atlas entry or a CPC row at 1e-5; the atlas list has no entry within 5e-3 with the same number of syzygies for any n; for n = 17 two CPC rows (N = 90 and 91, both with k = 42) are within 5e-3 in (T*, L*) at twice T* of this orbit, which is a coincidence of two numbers (see below). Not found in the sources checked.

PER n, IN PLAIN WORDS.
 S1 (branch point and roots): for n = 13 to 20 the member with nu = 1/n was found in the isosceles chart (L* of the member 2.976 to 3.230, the same members as for class C), the repeat closed with 8 pieces and the default tolerance, the second smallest singular value of the matrix [J | dF/dlam] is 3.4e-12 to 1.1e-11 (the third 2.5e-4 to 7.3e-4), so the null space is 2 dimensional; the bifurcation equation has two real roots, the repeat direction (|cos| with the repeat tangent 0.999997 to 1.0000000) and another one at an angle of 63.5 degrees (n = 13) growing to 65.2 degrees (n = 20) from the repeat direction.
 S2 (the curves): n = 13: both senses reach a zero (the two zeros agree in T* to 2.2e-10 and in L* to 2.9e-10, rotation left 6e-13 and 3e-12 turns); n = 14: both senses, but the second zero has 4.8e-8 turns left (a poorly converged zero, as for some class C zeros) and differs from the first by 4e-7 in T*; n = 15 and 16: sense 1 stops by a collapse of the step (after a path length of 9.6, at L* 2.694 and 2.726), sense -1 reaches a zero; n = 17 to 20: sense -1 stops by a collapse of the step (path length 9.6, L* at the end 2.757 to 2.844), sense 1 reaches a zero. The rotation left at all the zeros used is below 1e-11 turns except the second zero of n = 14. The collapse of the step was not investigated (as for class C, n >= 16): nothing is claimed about the curve beyond it. In every case the L* of all accepted points is below that of the member (the maximum of L* minus the member's is 0 at the first point), as for the stored class C curves (their maximum is +5e-10 or smaller, rounding of the first point). The end orbit has an L* lower than the member by 0.313 (n = 13) to 0.544 (n = 20).
 S3 (end orbit): the refinement to 30 digits converged (residual 1e-29 to 3e-27), the closure of the rounded values 5.7e-25 to 3.6e-24. The REBOUND distances (IAS15) after 1, 2, 5, 10, 20 periods are in the table for 1 and 20 periods and in data/class-i/rebound/ for the others: after one period 9e-15 to 3e-13 for all eight, as expected; after 20 periods the distance grows with the multiplier from 4e-8 (n = 13) to the size of the orbit (1.8 at n = 17, 1.5 at n = 18, 1.3 at n = 19, 0.68 at n = 20): the orbits are unstable, so an integration in double precision does not return after 20 periods for n >= 17; this is not part of the threshold (declared in the rules).

THE CRITERION. (a) symmetry class: met for all eight. (b1) T*, L* differ by far more than 100 times the larger closure: met for all eight (stated in advance as easy). (b2) the moduli of the largest multipliers differ by more than 1e-6 relative: met for all eight. Established (closure below 1e-20, REBOUND one period below 1e-9): all eight. So for all eight n the end orbit is DIFFERENT from the class C satellite of the same n, in the sense of the criterion: another symmetry class and other values; (a) carries the weight, as stated before.

WHAT THIS DOES NOT SHOW.
 - Only n = 13 to 20, only the upper nu, only apex body 0, and one non-repeat root per n (the null space is 2 dimensional, so there is no other). Nothing for n >= 21, the lower nu, the other apex bodies, orbits without these symmetries.
 - "Different" means another symmetry class and other T*, L*, multipliers; it says nothing about how the two families are related (whether they are part of one bifurcation structure), and it is not a statement about orbits in general. The picture of a stable and an unstable orbit of a pair (n = 5 to 12) does not carry over: here both are unstable, and Meyer's result (a qualitative analogy only, even for n <= 12) says nothing about this case.
 - Linear stability only; tier A only (50 digits); there is no second precision for an error estimate (the accuracy is judged from det - 1 and the closure, about 1e-24).
 - Nothing is known about why one sense of the curve stops by a collapse of the step for n >= 15 (class I) and n >= 16 (class C): it was not investigated; the stopped curves have L* far from a zero and nothing is claimed beyond them. The sense that fails is not the same sense for the two classes in every n (class I: sense 1 for n = 15, 16, sense -1 for n = 17 to 20; the class C labels come from the stored files); the labelling of the senses between the two charts was not compared, so no statement is made about it.
 - That the two senses end at the same orbit was checked only at the double precision zeros (n = 13: to 3e-10; n = 14: to 4e-7, limited by the poorly converged second zero), and only for n = 13 and 14; for n = 15 to 20 there is one zero. The 30 digit orbits are refined from the first zero of the file.
 - The atlas list is the local copy of 2026-10-09 (415 entries, rounded T* and L*); the CPC rows are 99; the repeat factors tried are 1 to 12. A coincidence at 5e-3 (n = 17, CPC) was read by the topological exponent, not by a full test.
 - The REBOUND 20 period distances only show that the orbits are unstable in double precision (growth with the multiplier); they do not test the orbits further.
 - Wording: found for n = 13 to 20 in the isosceles class, "not found in the sources checked" (atlas of 415 entries, 99 CPC rows). That says nothing about whether the orbits are known.
