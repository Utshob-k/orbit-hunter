Rules and predictions for test 2 (predictor B for the established k > 1 zeros) and test 1 (the upper branch of the satellites of Broucke's R family for n = 37 to 58, out of sample), copied from the local rules file. They were written on 2026-10-11 before any number of test 2 was computed and before any run of test 1 was started; any later change is declared in a section added below before it was run, with its results kept in separate files. The times are the clock of the machine. The results are in docs/r-family-satellites.md (the sections on the empirical relations and on n = 37 to 56); the scripts are tools/satellite-test2.mjs (test 2), tools/satellite-relations.mjs (section 5, the errors of test 1) and tools/satellite-sequence.mjs (the table). The runs of test 1 used a copy of tools/branch-point.mjs of the commit 41a074b in which only the paths differ (the imports of ../src, the trace file and the output folder); phase 2 (n = 57 and 58) is not reported here.

------------------------------------------------------------------ TEST 2 (existing data)
WHAT IS TESTED. Predictor B in the form T*_zero = n T*_R(nu = k/n) - delta_n for the k > 1 zeros of data/branch-points/<k>-<n>-<branch>-<theta>.json, with delta_n = a + b/n exactly as fitted on k = 1, n = 8 to 20
 (a = -0.0033397, b = 0.463315; no refit), and n T*_R(nu = k/n) = n times the T* of the member of the file (= T* of the first point of the satellite curve, the n fold repeat of the member).
WHICH ZEROS. The established ones: the zero reaches rotation 0 and its closure tier (data/branch-summary.json) is reliable: 2-5-upper-0.3636, 2-7-upper-0.2809, 2-9-upper-0.2227, 2-11-upper-0.1830,
 3-8-upper-0.3482, 3-10-lower-0.4021, 3-10-upper-0.2931, 3-11-upper-0.2696, 4-9-upper-0.4249, 5-12-upper-0.3728 (ten). Refined values (30 digits, data/satellite-candidates.json) where the zero has one
 (2/9 upper, 2/11 upper, 3/10 lower); for the others the stored zero (its rotation left is at most 3e-8 turns, which changes T* by about 3e-7, far below the bound).
HOLDING. A zero holds if |prediction - data| <= 0.005 (the bound of the test of robustness for T*). Reported per zero: prediction, data, error, holds or not.
EXPECTATION, written before the computation: B will not hold for any of the ten. Reason: for k = 1 the correction delta_n is 0.006 to 0.06 and small because the rotation excess eps_n of the repeat is small by
 construction (nu = 1/n); for k > 1 the excess is 0.0045 to 0.33 and delta is about 8 eps (0.036 to 2.4), while a + b/n is 0.03 to 0.09. The only zero with a delta near the fitted one is 2-9-upper (delta 0.036,
 fitted 0.048, error 0.012), which also fails the bound.
SEPARATE, DECLARED NOW AS A LABELLED VARIANT H (the heuristic delta = C eps found after seeing the data, so not a prediction; reported apart from B): T*_pred = n T*_member - 8 |eps|, with eps = the rotation of
 the first point of the satellite curve (turns), C = 8 fixed. Holds if |delta_pred - delta| <= 10 % of delta (a relative bound, because eps is large).
THE sqrt(n) FORM CANNOT BE APPLIED TO k > 1, to be shown with the numbers: it is a function of n alone fitted on the sequence nu = 1/n; at one n there are several k > 1 zeros (n = 11: k = 2, 3, 5) with different T*,
 and the form gives one value for each n. The T* of the zeros of the same n are listed.

------------------------------------------------------------------ TEST 1 (out of sample, n = 37 to 58)
TIME LIMIT. 6 hours wall-clock from the launch of the runs (the launch time is written down); every job is started with `timeout` for the time that is left.
METHOD SETTINGS, those of n = 29 to 36, unchanged: for every n the upper nu = 1/n member (theta of the crossing given with 6 digits, column 2 of the table below), `node bp-copy.mjs n theta --repeat-tol=1e-8 --pieces=16
 --control --write` (bp-copy.mjs = tools/branch-point.mjs of the repository at commit 41a074b, paths differ only); the limits of the continuation as committed: closest approach 0.03, 700 accepted steps, step 0.03 and
 6 % of the distance from the branch point, tangent turning < 0.35 rad, residual of the repeat 1e-8, member 1e-11, caps of the integration steps of src/perp.js and src/shooting.js as committed. 10 jobs at a time, in the order of n.
AN n IS DECIDED if at least one sense of the satellite curve reaches rotation 0. UNDECIDED if neither does (the limit that stopped each sense is reported: closest approach, collapse of the step, step limit, failure
 of the repeat solve or of the integration). An undecided n is not a result about the orbit. No stop rule: all n from 37 to 58 are run within the time limit.
FOR EVERY ZERO: refinement to 30 digits (tools/refine-mp.py, 30 digits); the refined values are used for everything below. Checks as for n = 13 to 36: T*, L*, rotation, closest approach, the syzygy word and the number
 of alignments (expected: (01)^n and 2n), the repeat test, closure tiers in double precision, the largest multiplier (src/relative.js) and the REBOUND check (tools/satellite-check.py), the comparison with all lists by
 T* and L* within 1e-5 (repeats up to 12, same alignments) and near 5e-3, and by start values for every orbit of my 102 at the same period within 5e-3 (tools/satellite-candidates.mjs, the atlas catalogue given).
PREDICTIONS (fits on n <= 20 only, no refit; the three formulas):
 B: T*_n = n T*_R(n) - delta_n, delta_n = -0.0033397 + 0.463315 / n (fit n = 8 to 20), n T*_R(n) from the stored trace (crossing of the upper nu = 1/n);
 sqrt: T*_n = 1.537242 n + 6.06149 + 1.82889 sqrt(n) (fit n = 8 to 20);
 L*: L*_n = 2.734438 - 0.964908 / n + 0.768383 / n^2 (fit n = 5 to 20, as published in docs/r-family-satellites.md).
HOLDING, per n and per formula: |T* error| <= 0.005 for B and for the sqrt form, |L* error| <= 1e-3 for the L* fit (the bounds of the test of robustness). Reported per n: the error of B, of the sqrt form and of the L* fit
 (prediction minus data), the multiplier, and for each formula the largest n up to which it holds at every decided n and the first n where it fails. A formula is judged only on decided n.
EXPECTATIONS, written before the runs, from the linear trend of the errors on n = 28 to 36 (the known zeros): B: error (zero - B) +3.0e-3 at n = 37 growing to +5.0e-3 at n = 58, so B is expected to hold up to
 n = 57 or 58 and to be at the bound at the end; sqrt: error (fit - zero) +2.4e-3 growing to +3.2e-3, so it is expected to hold for all n; L*: error (fit - zero) -5.4e-4 at n = 37 growing to -1.07e-3 at n = 58, so it is
 expected to hold up to n = 55 and to fail from n = 56. The multiplier: not predicted here (the earlier trends failed); it is reported.
