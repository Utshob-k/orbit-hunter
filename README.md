# Orbit Hunter

A search for periodic orbits of the planar three-body problem with equal masses and non-zero angular momentum, and PeriCont, which follows families of such orbits through close approaches of two bodies.

**The current version is 0.3.0**, on the branch [release-0.3](https://github.com/Utshob-k/orbit-hunter/tree/release-0.3) (tag [v0.3.0](https://github.com/Utshob-k/orbit-hunter/tree/v0.3.0), [release notes](https://github.com/Utshob-k/orbit-hunter/releases/tag/v0.3.0)). Its README says how to install it, how to run the tests and what the results are. The raw files behind its data/deep folder are on Zenodo: https://doi.org/10.5281/zenodo.23864862.

This branch, main, holds version 0.2.33 (2026-10-18), the search before PeriCont. Its files, among them [docs/results.md](docs/results.md), [docs/methods-and-limits.md](docs/methods-and-limits.md) and [docs/prior-work.md](docs/prior-work.md), show the state of that date.

No orbit found here is claimed to be new.

Correction (2026-11-06): the README and docs of versions 0.2.5 to 0.3.0, which stay as they are, say that the papers of Nauenberg (2001) and of Chenciner, Fejoz and Montgomery (2005) are not read, and from 0.2.15 on that the 2025 review of Li and Liao could not be read. These sentences date from October 2026 and were not updated later; all three were read in a later literature check (2026-11-03; the review and the paper of Chenciner, Fejoz and Montgomery in part). Reading them changed none of the numbers.
